Sumbu Virus Worm Trojan
Host Perlu file atau program sah sebagai tempat menempel Tidak perlu file induk Tidak menempel sebagai parasit; menyamar sebagai program utuh
Replikasi Menyalin diri saat file host dieksekusi atau dibagikan Mereplikasi diri sendiri lewat jaringan Tidak mereplikasi diri
Penyebaran Ikut file infektif yang dibagikan pengguna Merambat antar mesin di jaringan Sampai ke target karena pengguna menginstal
Interaksi user Wajib: file harus dijalankan atau disalin orang Tidak wajib untuk replikasi Wajib: manusia tertipu lalu menginstal
Tujuan tipikal Menginfeksi file atau program lain Menyebar luas dengan cepat antar sistem Membuka backdoor / akses tersembunyi
